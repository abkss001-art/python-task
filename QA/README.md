# STD Live — מערכת לניהול ותיעוד בדיקות מערכת (QA) בזמן אמת

אפליקציית ווב מלאה, מהירה ומודרנית לניהול ותיעוד בדיקות מערכת (**STD**) עבור צוותי QA ופיתוח, עם **סנכרון חי בזמן אמת (ללא צורך ברענון דף / F5)**, תמיכה מלאה ב-**RTL (עברית)** וטיפול מתקדם בצילומי מסך.

---

## ✨ תכונות מרכזיות

1. **סנכרון חי בזמן אמת בין כל המשתמשים**:
   - חיבור מובנה ל-**Firebase Realtime Database** ו-**Firebase Cloud Firestore**.
   - **אשף הגדרת ענן מובנה בממשק**: ניתן להדביק ישירות את קטע הקוד `firebaseConfig` מתוך Firebase Console ולייצר **קישור צוות ישיר** (שמכיל את הגדרות החיבור) כך שכל חבר צוות שנכנס לקישור מתחבר אוטומטית לאותו ענן.
   - **שרת סנכרון חי מובנה (SSE Live Server)**: גם לפני הזנת מפתחות Firebase, המערכת מסנכרנת בזמן אמת בין כל הדפדפנים והמכשירים המחוברים לשרת (לא מבוססת רק על `LocalStorage`).
2. **טיפול מושלם בצילומי מסך**:
   - **הדבקה מהירה (`Ctrl + V`) מהלוח (Clipboard)**: ניתן להדביק צילום מסך ישירות בתוך טופס התקלה, בתוך תגובה בשרשור ההערות, או אפילו בלחיצה על `Ctrl + V` במסך הראשי (פותח אוטומטית תקלה חדשה עם הצילום!).
   - תמיכה בגרירת קבצים (**Drag & Drop**) ובהעלאת מספר צילומי מסך לתקלה.
   - **תצוגה מקדימה לא חתוכה (`object-contain`)** בכרטיסיות ובטבלה.
   - **מסך מלא (Lightbox) עם זום והזזה (Pan)**: בלחיצה על תמונה נפתח Lightbox עם זום פנימה/החוצה (גלגלת עכבר, כפתורי `+/-`, כפתור **זום מובייל 250%**, לחיצה כפולה) וגרירת התמונה לקריאה ברורה של פרטים קטנים במסכי מובייל.
3. **מבנה ממשק ו-RTL מוקפד**:
   - יישור מלא לימין (`dir="rtl"`) ובידוד דו-כיווני (`unicode-bidi`) כך שמילים באנגלית (`CARGO`, `Safari`, `Chrome`) או מספרים לא שוברים את השורות.
   - **סרגל עליון למעבר מהיר בין מערכות**: `CARGO`, `נשקי ערד`, `כל המערכות` ואפשרות להוסיף מערכות חדשות בזמן אמת.
   - מעבר בלחיצת כפתור בין **תצוגת כרטיסיות (Cards)** מרווחת לבין **טבלה חכמה (Smart Table)** עם מיון עמודות ועריכה מהירה.
   - סינון וחיפוש מהיר לפי **מזהה תסריט**, **פלטפורמה** ו**סטטוס**, כולל ייצוא ל-**Excel (CSV)**.

---

## 🚀 הפעלה מהירה

```bash
npm install
npm run dev
```

לחץ על כפתור **"סנכרון חי"** בסרגל העליון כדי להדביק את ה-`firebaseConfig` של הפרויקט שלך, או הגדר אותו בקובץ `.env` / `src/firebaseConfig.ts`.
